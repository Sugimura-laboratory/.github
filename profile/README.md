# 🔬 杉村研究室 GitHub オーガナイゼーション (Sugimura Lab GitHub Organization)

[![Official Website](https://img.shields.io/badge/Official_Website-sugi--lab.net-blue?style=for-the-badge&logo=googlechrome)](https://www.sugi-lab.net)

杉村研究室の開発プロジェクト、オープンソースソフトウェア（OSS）、研究用コードを管理する公式GitHubオーガナイゼーションです。研究室に関する詳細な紹介やニュースは [公式ウェブサイト](https://www.sugi-lab.net) をご覧ください。

*This is the official GitHub organization for Sugimura Laboratory, managing our development projects, open-source software, and research code. For a detailed introduction and news about our laboratory, please visit our [official website](https://www.sugi-lab.net).*

## 📂 プロジェクトカテゴリ (Project Categories)

主要なリポジトリを分野別にまとめています。<br/>
*Our main repositories are grouped into the following categories.*

### 🌐 ウェブ＆アプリケーション (Web & Applications)
研究成果のデモンストレーションやウェブシステム。
*Web systems and applications developed as demonstrations of our research.*
- [**miniature**](https://github.com/Sugimura-laboratory/miniature) - ミニチュアプロジェクトのWebサイト *(Miniature project website)*
- [**appendixViewer**](https://github.com/Sugimura-laboratory/appendixViewer) - ECHONET Lite Appendix Viewer

### 🛠️ ハードウェア＆ファームウェア (Hardware & Firmwares)
デバイス制御用のファームウェアや関連ツール。
*Firmwares and tools for device control.*
- [**EL-Firmwares-for-Miniature**](https://github.com/Sugimura-laboratory/EL-Firmwares-for-Miniature) - ミニチュアデバイス向けのELファームウェア *(EL Firmwares for Miniature device)*
